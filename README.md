# 4D-UV-Quat-Diffusion

**Генерация изображений с помощью диффузионных моделей и 4D представления данных**

---

## 📖 Что это такое? (Простыми словами)

Это проект для создания искусственных изображений с помощью нейронных сетей. Представьте, что у вас есть художник-робот, который учится рисовать, глядя на тысячи картинок. После обучения он может создавать новые изображения "с нуля" - просто из случайного шума.

### Как это работает простыми словами:

1. **Обучение**: Модель смотрит на тысячи реальных изображений (например, фотографии птиц, машин, самолетов) и учится их "понимать"
2. **Генерация**: Когда обучение завершено, модель может создать новое изображение, постепенно превращая случайный шум в осмысленную картинку
3. **Особенность**: В отличие от обычных моделей, эта использует специальное "4D представление" - как будто каждое изображение разбивается на несколько слоев и вариантов одновременно

### Что означает "4D-UV-Quat"?

- **4D**: Обычное изображение - это 2D (ширина × высота). Мы добавляем еще 2 измерения (U и V), создавая "4D поле"
- **UV**: Это дополнительные измерения, которые позволяют модели видеть изображение с разных "углов" одновременно
- **Quat (Кватернионы)**: Специальная математическая структура для обработки данных в UV-пространстве, которая помогает модели лучше понимать связи между пикселями

## 🔬 Подробное техническое описание

### Архитектура модели

Проект реализует **диффузионную модель** (DDPM/DDIM) с **4D U-Net архитектурой** и **кватернионными UV-свертками**.

#### 1. Диффузионный процесс

**Forward процесс (обучение):**
- Берем реальное изображение `x₀`
- Постепенно добавляем гауссовский шум: `x₁, x₂, ..., xₜ, ..., xₜ`
- На шаге `t` изображение становится: `xₜ = √(ᾱₜ)·x₀ + √(1-ᾱₜ)·ε`, где `ε ~ N(0,I)`
- Модель учится предсказывать шум `ε` по зашумленному изображению `xₜ` и времени `t`

**Reverse процесс (генерация):**
- Начинаем с чистого шума `xₜ ~ N(0,I)`
- Итеративно удаляем предсказанный шум: `xₜ₋₁ = f(xₜ, ε_pred, t)`
- После `T` шагов получаем сгенерированное изображение `x₀`

#### 2. 4D Представление данных

**Преобразование изображения в 4D поле:**

Обычное изображение: `[Batch, Channels, Height, Width]` = `[B, C, H, W]`

4D поле: `[Batch, Channels, X, Y, U, V]` = `[B, C, X, Y, U, V]`

Где:
- `X = H // s`, `Y = W // s` (обычно `s=2`, поэтому размеры уменьшаются в 2 раза)
- `U, V ∈ {0, 1, ..., s-1}` - дополнительные измерения

**Как это работает:**
```python
# Изображение 32×32 разбивается на блоки 2×2
# Каждый блок становится "точкой" в 4D пространстве
# Создается 16×16×2×2 = 1024 "точек"
```

**Преимущества:**
- Модель видит изображение с разных "сдвигов" одновременно
- Лучше обрабатывает периодические паттерны
- Уменьшает артефакты на границах

#### 3. Кватернионные UV-свертки

**Кватернион** - это расширение комплексных чисел: `q = a + bi + cj + dk`

В нашем случае:
- Каждый канал обрабатывается независимо
- Для каждого канала создаются 4 сверточных ядра: `A, B, C, D`
- Результат вычисляется через матрицу Гамильтона:
  ```
  y = A*x + B*roll(x, U) + C*roll(x, V) + D*roll(x, U, V)
  ```

**Особенности:**
- `kernel_size=1`: Только центральный пиксель (быстрее)
- `kernel_size=3`: Включает соседние пиксели в UV-пространстве (лучше качество)
- Циклический паддинг по U и V для сохранения периодичности

#### 4. U-Net архитектура

Стандартная U-Net структура, адаптированная для 4D данных:

```
Вход [B,C,X,Y,U,V]
  ↓
Входная проекция (ConvXY)
  ↓
Downsampling блоки (×4 уровня)
  ├─ ResBlock4D (ConvXY → QuaternionUVConv)
  ├─ ResBlock4D (downsampling)
  └─ ...
  ↓
Middle блок (ResBlock4D)
  ↓
Upsampling блоки (×4 уровня)
  ├─ ResBlock4D
  ├─ ResBlock4D (upsampling)
  └─ ...
  ↓
Выходная проекция (ConvXY)
  ↓
Выход [B,C,X,Y,U,V]
```

**Компоненты:**
- **ConvXY**: Обычная 2D свертка по пространственным измерениям (X, Y)
- **QuaternionUVConv**: Кватернионная свертка по UV измерениям
- **GroupNorm**: Нормализация по группам каналов
- **Time Embedding**: Встраивание временного шага `t` для контроля процесса диффузии

## ⚙️ Конфигурация

Основные параметры в `configs/cifar10.yaml`:

### Данные
- `image_size: 32` - Размер изображений (CIFAR-10)
- `channels: 3` - Количество каналов (RGB)
- `batch_size: 32` - Размер батча
- `gradient_accumulation_steps: 2` - Эффективный batch = 64

### Модель
- `stride_s: 2` - Размер блока для fold/unfold (U,V ∈ {0,1})
- `uv_kernel: 1` - Размер ядра кватернионной свертки (1 или 3)
- `base_channels: 64` - Базовое число каналов
- `channel_mults: [1, 2, 2, 2]` - Множители каналов по уровням
- `num_res_blocks: 2` - Количество Res блоков на уровень

### Диффузия
- `num_timesteps: 1000` - Количество шагов диффузии
- `beta_schedule: cosine` - Расписание бета (cosine или linear)

### Оптимизация
- `lr: 2.0e-4` - Learning rate
- `ema_decay: 0.999` - Коэффициент EMA
- `mixed_precision: true` - Использование FP16

### Регуляризация
- `lambda_uv: 0.1` - Вес регуляризации UV градиентов
- `quat_weight_norm: false` - Нормировка кватернионных весов (Этап B)

## 🔄 Процесс обучения

### Что происходит во время обучения:

1. **Загрузка данных**: CIFAR-10 автоматически скачивается при первом запуске
2. **Преобразование в 4D**: Каждое изображение преобразуется в 4D поле
3. **Добавление шума**: Случайный временной шаг `t` и шум `ε`
4. **Предсказание**: Модель предсказывает шум `ε_pred`
5. **Вычисление потерь**: `loss = ||ε - ε_pred||² + λ_uv * ||∇_UV x||²`
6. **Обновление весов**: Backpropagation и оптимизация
7. **EMA обновление**: Обновление экспоненциально скользящего среднего

### Метрики обучения:

- **loss**: Общая потеря
- **loss_eps**: Потеря предсказания шума
- **loss_uv**: Регуляризация UV градиентов
- **lr**: Текущий learning rate

### Чекпоинты:

- `ckpt_last.pt` - Последний чекпоинт (обновляется каждые 1000 шагов)
- `ckpt_{N}.pt` - Чекпоинты каждые 20000 шагов

## 🎨 Генерация изображений

### Процесс генерации (DDIM):

1. **Инициализация**: Создается случайный шум `x_T ~ N(0,I)` в 4D формате
2. **Итеративное денойзинг**: Для каждого шага `t = T, T-1, ..., 1, 0`:
   - Модель предсказывает шум: `ε_pred = model(x_t, t)`
   - Вычисляется оценка оригинала: `x₀_pred = (x_t - √(1-ᾱ_t)·ε_pred) / √(ᾱ_t)`
   - Обновляется состояние: `x_{t-1} = √(ᾱ_{t-1})·x₀_pred + √(1-ᾱ_{t-1})·ε_pred`
3. **Преобразование обратно**: 4D поле → 2D изображение с усреднением по сдвигам
4. **Денормализация**: Из диапазона [-1, 1] в [0, 1]

### Параметры генерации:

- `steps`: Количество DDIM шагов (больше = лучше качество, но медленнее)
- `shift_avg`: Усреднение по сдвигам (U,V) для лучшего качества
- `eta`: Параметр стохастичности (0 = детерминированный DDIM)

## 🐛 Решение проблем

### Проблема: Out of Memory (OOM)

**Решение:**
- Уменьшите `batch_size` в конфиге
- Увеличьте `gradient_accumulation_steps`
- Модель автоматически обрабатывает OOM и пропускает проблемные батчи

### Проблема: Медленное обучение

**Решение:**
- Убедитесь, что используется CUDA
- Проверьте `mixed_precision: true`
- Уменьшите `num_workers` если не хватает RAM

### Проблема: Плохое качество генерации

**Решение:**
- Продолжите обучение (нужно 100k+ шагов)
- Используйте больше DDIM шагов (100+)
- Используйте более низкий уровень шума для тестирования

### Проблема: Модель не продолжает обучение

**Решение:**
- Проверьте наличие `ckpt_last.pt` в `runs/cifar10/`
- Укажите конкретный чекпоинт: `--resume runs/cifar10/ckpt_60000.pt`

## 📚 Дополнительная информация

### Математические основы

**Диффузионные модели:**
- Forward процесс: `q(x_t|x_0) = N(x_t; √(ᾱ_t)x_0, (1-ᾱ_t)I)`
- Reverse процесс: `p_θ(x_{t-1}|x_t) = N(x_{t-1}; μ_θ(x_t,t), Σ_θ(x_t,t))`
- Loss: `L = E[||ε - ε_θ(x_t, t)||²]`

**Кватернионы:**
- Кватернион: `q = a + bi + cj + dk`
- Умножение: `i² = j² = k² = ijk = -1`
- Норма: `|q| = √(a² + b² + c² + d²)`

**4D Представление:**
- Fold: `[B,C,H,W] → [B,C,X,Y,U,V]` где `X=H//s, Y=W//s`
- Unfold: `[B,C,X,Y,U,V] → [B,C,H,W]` через усреднение по сдвигам
