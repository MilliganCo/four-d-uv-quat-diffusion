# README_STAGE_B.md - Инструкции для Stage B обучения
# Обучение с uv_kernel=3, разрешением 64x64 и текстовыми промптами

## Что было изменено

### 1. Конфигурация (`configs/cifar10_stage_b_64x64.yaml`)
- ✅ `uv_kernel: 3` - Используется kernel размером 3 для лучшего качества
- ✅ `image_size: 64` - Увеличено разрешение до 64x64
- ✅ `use_text_conditioning: true` - Включена условная генерация
- ✅ `quat_weight_norm: true` - Включена нормировка кватернионных весов
- ✅ `batch_size: 16` - Уменьшено для экономии памяти (64x64 требует больше VRAM)
- ✅ `gradient_accumulation_steps: 4` - Эффективный batch = 64

### 2. Новые файлы

**Модели:**
- `models/text_encoder.py` - Текстовый энкодер для условной генерации
- `models/unet4d.py` - Обновлен для поддержки текстовых эмбеддингов

**Датасеты:**
- `datasets/cifar10_64x64.py` - CIFAR-10 с апскейлом до 64x64 и текстовыми метками

**Скрипты:**
- `train_conditional.py` - Обучение с поддержкой текстовых промптов
- `generate_with_prompt.py` - Генерация с текстовыми промптами
- `start_training_stage_b.bat` - Удобный запуск обучения

### 3. Изменения в существующих файлах

- `diffusion/schedules.py` - `ddim_sample` теперь принимает `text_emb`
- `models/unet4d.py` - Добавлена поддержка текстовых эмбеддингов в `ResBlock4D` и `UNet4D`

## Как использовать

### Запуск обучения

```bash
# Простой запуск
python train_conditional.py --config configs/cifar10_stage_b_64x64.yaml

# Или через bat-файл
start_training_stage_b.bat

# Продолжение обучения
python train_conditional.py --config configs/cifar10_stage_b_64x64.yaml --resume runs/cifar10_stage_b_64x64/ckpt_last.pt
```

### Генерация с текстовыми промптами

После обучения можно генерировать изображения конкретных классов:

```bash
# Генерация кошек
python generate_with_prompt.py --ckpt runs/cifar10_stage_b_64x64/ckpt_20000.pt --prompt "cat" --n 16 --steps 100

# Генерация по метке класса (3 = cat)
python generate_with_prompt.py --ckpt runs/cifar10_stage_b_64x64/ckpt_20000.pt --class 3 --n 16 --steps 100

# Генерация птиц
python generate_with_prompt.py --ckpt runs/cifar10_stage_b_64x64/ckpt_20000.pt --prompt "bird" --n 16 --steps 100
```

### Доступные классы CIFAR-10:

- `0` - airplane (самолет)
- `1` - automobile (автомобиль)
- `2` - bird (птица)
- `3` - cat (кошка) ⭐
- `4` - deer (олень)
- `5` - dog (собака)
- `6` - frog (лягушка)
- `7` - horse (лошадь)
- `8` - ship (корабль)
- `9` - truck (грузовик)

## Особенности

### Текстовые промпты

Модель использует простой энкодер меток классов:
- Вход: метка класса (0-9)
- Выход: текстовый эмбеддинг размерности 128
- Эмбеддинг добавляется к каждому ResBlock4D через проекцию

### Разрешение 64x64

- CIFAR-10 автоматически апскейлится до 64x64
- 4D поле: 32×32×2×2 (вместо 16×16×2×2 для 32x32)
- Требует больше памяти, но дает лучшее качество

### uv_kernel=3

- Использует соседние пиксели в UV-пространстве
- Циклический паддинг для сохранения периодичности
- Лучше качество, но медленнее чем kernel=1

## Ожидаемые результаты

- **Разрешение**: 64×64 пикселя (в 4 раза больше пикселей чем 32×32)
- **Качество**: Лучше детализация благодаря большему разрешению и kernel=3
- **Условность**: Можно генерировать конкретные классы (кошки, птицы и т.д.)

## Требования к памяти

- **VRAM**: ~8-10 GB для batch_size=16
- **RAM**: ~4-6 GB
- **Диск**: ~2 GB для чекпоинтов

## Примечания

1. **Обучение займет больше времени** из-за большего разрешения и kernel=3
2. **Текстовые промпты работают только с классами CIFAR-10** - нельзя задать произвольный текст
3. **Для произвольных текстовых промптов** нужен CLIP энкодер (можно добавить позже)
